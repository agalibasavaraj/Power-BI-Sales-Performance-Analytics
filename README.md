# Power BI Sales Performance Analytics — Portfolio & Mentorship Studio

Welcome to the **Power BI Sales Performance Analytics** portfolio project.

This repository contains the complete end-to-end data analytics workflow built for Power BI Desktop, accompanied by an interactive browser-based learning workbench and validator.

## Project Structure
- `Sales-Performance-Analytics/data/`: Raw and normalized CSV datasets (Fact & Dimensions).
- `Sales-Performance-Analytics/dashboard/`: Power BI Data Source connector (`.pbids`), visual JSON theme, and canvas setup instructions.
- `Sales-Performance-Analytics/sql/`: Production SQL scripts for database schema creation, DAX-to-SQL KPI reconciliation, window functions, and Pareto analysis.
- `Sales-Performance-Analytics/docs/`: Detailed phase-by-phase documentation:
  - `data_profile.md` (Phase 1)
  - `powerquery_transformations.md` (Phase 2)
  - `data_model.md` (Phase 3)
  - `dax_measures.md` (Phase 4)
  - `dashboard_design_specification.md` (Phase 5)
  - `validation_and_business_insights.md` (Phase 6)
  - `interview_qa_masterclass.md` (Technical Interview Preparation)
- `Sales-Performance-Analytics/README.md`: Portfolio presentation README.
- `src/`: Interactive Power BI Studio & Mentorship Web Applet (runs in AI Studio).
